
Project Overview:
We built a system for a hospital. It keeps track of Patients, Doctors, and Bills. It makes sure everyone’s health info is safe and all payments are clear.

Key Design Decisions:
Keep Everything: We never delete info. We just use labels like "Cancelled" or "Inactive" so we don't lose history.
Payment Choice: The system allows people to pay with cash or card, which helps with partial payments.
